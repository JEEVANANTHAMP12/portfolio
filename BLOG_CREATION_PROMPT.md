## WRITING STYLE RULES

When writing blog posts for me, follow these rules:

1. **Voice:** Write in FIRST PERSON as ME (Jeevanantham). Not third person. Not generic.
2. **Tone:** Conversational, like teaching a friend over coffee. Casual but knowledgeable.
3. **Structure:** Every post must have a personal story or experience that leads into the technical content.
4. **Teaching style:** Explain concepts like you're teaching someone who is curious but hasn't done it before.
5. **Code examples:** Include REAL code with comments explaining each line. Not just snippets.
6. **Honesty:** Include mistakes, struggles, and "aha" moments. Don't make it sound perfect.
7. **Practical advice:** End every post with actionable tips the reader can use TODAY.
8. **Length:** 1500-3000 words. Not too short, not too long.
9. **Sections:** Use <h2> for main sections, <h3> for subsections.
10. **Code blocks:** Use <pre><code> for all code. Add comments inside code.
11. **Lists:** Use <ul>/<li> for tips and key points.
12. **Quotes:** Use <blockquote> for key takeaways or memorable moments.
13. **Images:** Use Unsplash URLs for hero images. Pick images that match the topic.

## BLOG POST TEMPLATE

Use this HTML structure for every blog post:

```html
<h2>The Moment I Started</h2>
<p>Open with a personal story. When did you first encounter this topic? What were you struggling with? What made you curious? Be specific — mention the exact day, the exact problem, the exact feeling.</p>

<h2>What This Thing Actually Is</h2>
<p>Explain the concept in plain language. Use an analogy. Compare it to something the reader already knows. Avoid jargon unless you define it first.</p>
<p>For example:</p>
<pre><code>// Show a simple, working example
// Comment every line so the reader understands what each part does
const example = "like this";
</code></pre>

<h2>How I Built It (or Learned It)</h2>
<p>Tell the step-by-step story. What did you try first? What broke? What did you Google? What tutorial did you follow? What clicked?</p>
<ul>
    <li><strong>Step 1:</strong> Explain what you did and why</li>
    <li><strong>Step 2:</strong> Explain what went wrong and how you fixed it</li>
    <li><strong>Step 3:</strong> Explain what you learned from the experience</li>
</ul>

<h2>What I Wish I Knew Earlier</h2>
<p>Share the mistakes you made so others don't have to. Be honest about what confused you.</p>
<blockquote>Put your single most important takeaway here — the one thing the reader should remember.</blockquote>

<h2>Try It Yourself</h2>
<p>Give the reader something concrete to do. A link to a resource, a mini-project idea, a code challenge. End with encouragement.</p>
```
